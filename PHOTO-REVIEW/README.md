# Frontal image review

[Bremen sample](bremen-frontal-sample.png) is an AI-retouched, illustrative draft made from the official uncoloured 2026 Bremen asset and the existing coloured photo as a positioning reference. It is not used as a catalogue photograph. Fine engraving can differ from the actual coin.

The user requires all uncoloured images to be upright/frontal, consistently sharp and the same displayed coin dimensions as the coloured images. Display geometry has been matched and tested. Consistent photographic detail remains unfinished: six originals are 270px and most others are 540px, while coloured originals are 1600px. CSS framing cannot restore missing detail.

An optional preference question was sent: authentic high-resolution photos (recommended) or clearly labelled edited illustrations. No answer has been received. Current catalogue images remain the authentic source files; the sample is for comparison only.

Research files and helpers are outside the checkout under /tmp/numista-coins, /tmp/commons-coins and /workspace/onboarding-tools. Numista's primary obverse images mostly carry non-commercial licences; wide secondary images are coin edges, not obverse candidates. Commercially usable Wikimedia candidates were found for Bremen (CC BY-SA 4.0) and Maria Callas (CC BY 4.0). Those were not adopted as a partial mixed-style cohort. The Commons search API returned 429 after the initial results; honour throttling and use cached metadata before further research.

The original generated asset remains at /workspace/generated_images/exec-e55df7f6-9e95-4035-8c30-c02aa7bfb99d.png. Original photographic files are preserved. Website domain, prices, shipping and upstream company repository are unchanged.
